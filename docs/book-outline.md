## 第一部：物理底座锚定（Substrate Anchoring）

> 核心问题：如何确保智能体的"完成声称"锚定于物理现实而非虚拟幻觉？

### 模式 01：物理底座穿透核验模式（Substrate Penetration Pattern）
- 意图：消除抽象虚拟环境造成的虚假完成，强制就地穿透至真实物理源码树与原生构建工具链
- 失效场景：隔离虚构 / 截断拦截 / 非就地构建
- 形式化锚点：公理 I（物理非信任）

### 模式 02：现实审计否决模式（Reality Audit Veto Pattern）
- 意图：独立审计通道对智能体声称的"完成"进行物理复核，否决未穿透的伪信号
- 失效场景：审计通道被同一模型实例自评 / 审计日志可被篡改
- 形式化锚点：公理 I + 定理 3.1（评估解耦）

### 模式 03：脚手架与解题域双阶段隔离模式（Two-Phase Mandate Pattern）
- 意图：将"搭建测试脚手架"与"编写业务逻辑"强制分离，防止脚手架污染解题域
- 失效场景：脚手架代码泄漏至生产路径 / 测试与实现耦合导致虚假通过

## 第二部：认知注意力管理（Cognitive Attention Management）

> 核心问题：如何在百万行代码库中驯服上下文退化（Context Rot），保持智能体极致专注？

### 模式 04：任务级最小特权投影模式（Task-Level PoLP Projection Pattern）
- 意图：对上下文施加最小特权原则（PoLP），仅注入当前子任务充要上下文
- 形式化锚点：公理 II（注意力熵增）——$P_{\text{violate}}(\rho) \ge 1 - e^{-\alpha\rho}$

### 模式 05：两阶段宏微观渐进设计展开模式（Macro-Micro Elaboration Pattern）
- 意图：先宏观架构决策（低带宽、高抽象），再微观实现展开（高带宽、低抽象），避免上下文稀释
- 失效场景：宏微观混杂导致关键决策被无关细节淹没

### 模式 06：流式拓扑分解与选择性断点续跑模式（Streaming Decomposition & Selective Resume Pattern）
- 意图：将大型任务拓扑分解为流式子任务序列，支持断点续跑与选择性重入
- 形式化锚点：公理 II + 定理 3.1（变异局部性）

## 第三部：执行韧性（Execution Resilience）

> 核心问题：如何保障代码变异与编译系统因果律的严谨单调性，打破自愈黑洞？

### 模式 07：沙箱驱动-导航结对微循环模式（Driver-Navigator Pairing Pattern）
- 意图：驱动者（写代码）与导航者（审代码）在沙箱内微循环，实时物理反馈
- 失效场景：单智能体自写自审导致确认偏误

### 模式 08：白盒隐式分支嗅探与内部锚定模式（Implicit Branch Sniffing & Internal Invariants Pattern）
- 意图：通过白盒分析识别隐式分支与内部不变量，锚定测试覆盖盲区
- 失效场景：黑盒测试无法触及的隐式路径

### 模式 09：幂等变异日志与物理时钟补偿模式（Idempotent Journaling & Mtime Touch Pattern）
- 意图：变异动作具备唯一规范化签名日志，物理时间戳严格单调，防止重试状态错位
- 形式化锚点：公理 III（变异因果律单调）——可观测 ⟺ mtime 严格正向跳变

## 第四部：并发协调（Concurrency Coordination）

> 核心问题：如何终结多智能体并发竞争的混乱与死锁？

- 意图：分布式物理底座上的租约锁协议，互斥写权限 + 看门狗活性保障

- 意图：单一主写者 + 多副本读者，读操作不阻塞写但需版本一致性校验

### 模式 12：对等智能体协议桥接模式（Peer-Agent Protocol Bridge Pattern）

## 第五部：结晶免疫（Crystallization Immunity）

- 意图：未终审经验一律视为 DRAFT_SUSPECT，严禁横向传播；双盲过滤后准入全局知识库

### 模式 15：污染模式拒识模式（Tainted Pattern Rejection Pattern）
- 意图：识别并拒识已被污染的经验模式，防止毒株在记忆库中建立谱系

### 模式 18：隐藏 Oracle 沙箱模式（Hidden Oracle Sandbox Pattern）

## 第九部：生产韧性（Production Resilience）

> 核心问题：如何在生产部署后持续保障运行时质量，并将生产缺陷转化为系统免疫力？

### 模式 23：生产环境运行时监控与异常嗅探模式（Production Runtime Anomaly Sniffing Pattern）
- 意图：将物理负反馈从"部署前"延伸至"部署后"，持续监控生产运行时状态，嗅探异常模式
- 形式化锚点：公理 I 扩展（运行时指标作为物理底座）、定理 3.1 扩展（状态可观测性持续保障）
- 失效场景：部署后性能静默衰减 / 资源泄漏累积 / 生产特有异常未萃取

### 模式 24：生产缺陷萃取与热修复闭环模式（Production Defect Crystallization & Hotfix Loop Pattern）
- 意图：将生产缺陷萃取为经验资产，触发热修复闭环，防止同类缺陷跨代际传播
- 形式化锚点：公理 IV 扩展（缺陷经验终审晋升）、公理 III 扩展（热修复因果单调）
- 失效场景：错误修复模式病毒式传播 / 热修复未验证直接上线 / 环境参数泛化
