# 扩大经验验证：实验计划（公理 II 增长律与 SNR 衰减率）

> 对应形式化：`formal_proof/IACFormalization/src/IACFormalization/Axiom2_AttentionDilution.lean`
> 首轮结果：`experiments/attention_growth/results.json`（GPT-2，≤800 token，ĉ 与 1/(1+γ̂) 相对误差 0.01%）
> 本计划目标：将单点验证扩展为**可证伪、可复现、跨模型跨尺度**的实验结论。

## 1. 待验命题（与形式化一一对应）

| 编号 | 命题 | 形式化对应 | 类型 |
| :--- | :--- | :--- | :--- |
| **H1** | 目标注意力质量不随冗余增加：$a(\rho+1) \le a(\rho)$ | `AttentionMechanism.ha_nonincr` | 结构前提 |
| **H2** | 无关质量单调增长：$b(\rho+1) \ge b(\rho)$ | `hgrowth` 的弱化形式 | 结构前提 |
| **H3** | 增长律形态判别：几何 $b(\rho)\approx b_0(1+\gamma)^\rho$ vs 线性 vs 次线性/饱和 | `snr_geometric_decay` vs `snr_polynomial_decay` 的前提分支 | 关键判别 |
| **H4** | ~~衰减率互反关系：$\hat c = 1/(1+\hat\gamma)$~~ → **重述为：目标质量 $a$ 与 $\rho$ 无关**（$\hat\beta_a = 0$） | `AttentionMechanism.ha_nonincr`（可强化为 `ha_const`） | **定义同一性**，非独立验证 |
| **H5** | 长程行为：是否存在普遍饱和点 $\rho^*$，使 $\rho>\rho^*$ 后前提失效 | 决定 `DilutionDynamics` 的适用域 | 边界刻画 |
| **H6** | 下游效应：违约概率下界 $P_{\text{violate}}(n) \ge 1 - c^n$ 与任务正确率实测一致 | `violation_prob_lower_bound` | 端到端验证 |

> 注意区分：H1–H3 是**前提**（其真实性是纯经验问题）；H6 是理论对工程后果的预测。
>
> **H4 的修订（重要）**：`c := 1/(1+γ)` 在形式系统里是**定义**（[Axiom2_AttentionDilution.lean 第 194-197 行](../../formal_proof/IACFormalization/src/IACFormalization/Axiom2_AttentionDilution.lean#L194-L197)），而实测 $\operatorname{snr}=a/b$，故恒有
> $$\operatorname{slope}(\log\operatorname{snr}) = \operatorname{slope}(\log a) - \operatorname{slope}(\log b).$$
> 只要 $a$ 与 $\rho$ 无关，$\hat c \equiv 1/(1+\hat\gamma)$ **代数恒成立**，与实验无关。原 H4 因此不是独立验证（首轮 0.01% 误差只是该恒等式的数值表现，不能作为"互反关系被证实"的证据）。H4 的真实检验对象是 **$a$ 的 ρ-独立性**——即唯一真正承重的经验前提 `ha_nonincr`（见 §4.2 修订）。

## 2. 首轮结果的三个局限（本计划要消除的）

1. **模型太弱**：GPT-2（124M）的注意力集中度高，稀释温和（SNR 仅降 21%），γ̂ ≈ 2×10⁻⁴/token 过小，几何/线性不可区分（数学上一阶等价）；
2. **上下文太短**：≤800 token，未触及生产级长度（32k–1M），无法观察 H5 的饱和/失效行为；
3. **无关填充太中性**：自然文本填充与 needle 语义距离远；真实场景中的无关上下文常含**近义干扰项**（Lost in the Middle / Context Rot 报告的主要退化源）。

### 3.2 变量设计

- **ρ（无关量）**：0, 0.5k, 1k, 2k, 4k, 8k, 16k, 32k, 64k, 128k（按模型上限截断；对数等距 + 线性加密双采样）；
- **填充类型**（三水平）：
  - F1 中性自然文本（首轮方案，对照）；
  - F2 **近义对抗填充**：与 needle 同模板不同取值的句子（如其他"访问码"），最强的稀释诱导；
  - F3 重复填充（同一无关句循环），检验结构性重复是否改变增长律形态；
- **needle 位置**（三水平）：上下文的 10% / 50% / 90%（控制 Lost in the Middle 位置效应）；
- **needle 类型**：事实句（访问码）、指令句（"必须以 JSON 回答"）、多跳事实（A→B→C 链）。
  > **实现现状（须如实声明）**：`measure_growth_law_e3.py` 目前只实现**事实句**一类（`NEEDLE_TEMPLATES` 全为访问码模板），指令句与多跳**尚未实现**。故 E2/E3 中 needle 类型因子实际退化为**单水平**，"跨 needle 类型的稳健性"不在本轮证据范围内。
- **重复**：每 cell 5 个 needle 实例 × 3 个随机种子，共 15 次测量。

### 3.3 测量协议（与首轮一致 + 扩展）

- 注意力来源（**已修订**）：**不再**用 `output_attentions=True` 读全矩阵（128k 下 $[1,H,S,S]$ 单层即 ~1.1 TB，不可驻留）。改为 `attn_implementation="flash_attention_2"` 前向 + `forward_pre_hook` 截获 `hidden_states`/`position_embeddings`，按 Qwen2Attention 数学**仅重算查询位** $q_{\text{pos}}$ 的行分布 $[1,H,n_q,S]$（fp32 softmax 后立即聚合成标量）。**不得依赖 SDPA 自动派发**：本卡（海光 gfx936）传入 4D 因果掩码会使后端静默退回 math 实现并物化全矩阵（1.5B@32k 即 51.5 GB，作业 941735 实测 OOM）。L3 黑盒仅测 H6；
- $a(\rho)$：查询位（末尾问题）对 needle token 的注意力质量；$b(\rho)$：对填充 token 的总质量；$\operatorname{snr}=a/b$；
- **三通道分解（新增，必须补记）**：定理把 softmax 二分为 $a+b$，但实测 $a+b\neq 1$——**BOS/attention sink、指令 token** 亦占有质量。故须显式记录**残差通道** $r := 1-a-b$。若 $r$ 随 $\rho$ 系统变化，则"$b$ 的几何增长"中可能混有"sink 质量流出"，稀释的机制归因即被污染。**E3 现有作业未记录 $r$，须由 E3b 补测**（见 §9）。
- **逐头原始序列（新增）**：形式系统中所有定理均为**逐 (层,头)** 命题，而当前汇报量为"逐层头均值 → 跨层均值"。为支撑"逐头不等式 → 聚合量"的推理桥（§8 T5），须增记**逐头** $a,b$ 序列，而非仅其层内均值。
- **逐层×逐头分解**：除均值外保留每层每头序列，检验"稀释是否集中于特定层"（若稀释集中于少数层，聚合均值会掩盖结构）；
- **归一化对照**：同时记录排除特殊 token（BOS/attention sink）前后的 b——sink 效应已知会扭曲质量分布；
- H6 任务层：每 cell 测任务正确率（needle 事实问答/指令遵循），与 $1 - c^n$ 下界对照。

## 4. 统计与判别方法

1. **增长律模型选择**（H3）：对 $b(\rho)$ 序列拟合四类模型——几何、线性、幂律 $b_0\rho^\beta$、饱和型 $b_\infty(1-e^{-\lambda\rho})$——以 **AIC/BIC + 留出段 RMSE** 双重判别，不预设几何律胜出；
2. **前提检验**（H4 重述后成为**核心**）：对几何区做 $\log a \sim \rho$ 回归，报告斜率 $\hat\beta_a$ 与 **bootstrap 95% CI**（按 needle×种子重抽样 1000 次）；判据为 $\hat\beta_a$ 与 0 **无显著差异**，并报告 $a$ 的相对漂移 $|a(\rho)-a(0)|/a(0)$。这是唯一真正承重的经验前提（`ha_nonincr`/`ha_const`）。
   同时保留 $\hat c$、$\hat\gamma$ 的原拟合，但 $|\hat c - 1/(1+\hat\gamma)|$ **仅作口径一致性 sanity check**（理论上恒为 0），**不再作为证据陈述**；
3. **前提检验**（H1/H2）：报告违反率（$\Pr[a(\rho+1)>a(\rho)]$ 的样本比例）及其置信区间，而非仅看均值——单步违反是否可归咎于噪声；
4. **饱和点估计**（H5）：对数序列上变点检测（CUSUM / ruptures PELT），若存在 $\rho^*$ 报告其位置与模型/填充类型的依赖关系；
5. **预注册式证伪标准**（先于实验写下）：
   - 若 F2 对抗填充下 $b$ **不增长**或 $a$ **显著上升**，则 H1/H2 在该域失效，`AttentionMechanism` 的适用域须收缩并在正文注明；
   - 若几何区内 $\hat\beta_a$ 的 95% CI **不含 0**（即 $a$ 随 $\rho$ 显著变化），则 `ha_nonincr` 在实测层被证伪，`AttentionMechanism` 的适用域须收缩（这也等价于原 H4 的失败，但表述不再是循环的）；
   - 若残差通道 $r(\rho)$ 随 $\rho$ 显著单调变化（例如 $\mathrm{d}r/\mathrm{d}\rho>0$ 且 bootstrap CI 不含 0），则**二通道模型不足**，$b$ 的增长不能单独归因于填充竞争，须引入 sink 通道并重述量守恒（§8 T2）；
   - 若 H6 中实测正确率**优于** $1-c^n$ 下界承诺的衰减速度，说明下界过保守，需检查违约概率定义与任务的对应关系。
6. **W* 补偿阈值检测（E4 新增，2026-10-20）**：核心洞察——SNR 衰减（公理 II 层面）与任务正确率衰减之间存在**补偿阈值 W***：$\rho < W^*$ 时模型的注意力补偿机制（sink、KV cache 优化、长上下文训练对齐）抵消 SNR 衰减，正确率 ≈ 100%；$\rho > W^*$ 时补偿失效，正确率陡降。$W^*$ 与模型能力正相关。判读：
   - **推论 1（相变存在）**：对 Qwen 正确率序列做变点检测（CUSUM/PELT），若存在 $W^*$ 使正确率在其附近从 >90% 陡降至 <50%，则支持补偿阈值模型；
   - **推论 3（SNR 衰减先于任务衰减）**：将 E3 的 $\operatorname{snr}(\rho)$ 与 E4 的 $p_{\text{correct}}(\rho)$ 对齐作图，若 $\operatorname{snr}(\rho)$ 在 $\rho \ll W^*$ 时已显著衰减而 $p_{\text{correct}}$ 仍 ≈ 1，则确认"SNR 衰减不直接传导为任务失败"，公理 II 的 `violation_prob`（SNR 相对损失）≠ 任务失败概率；
   - **推论 2（W* 与能力正相关）**：跨模型对比 $W^*_{\text{Qwen-1.5B}} < W^*_{\text{Qwen-7B}} < W^*_{\text{Kimi}}$。若 Kimi 在 1M 内正确率仍 ≈ 100%，记录 $W^*_{\text{Kimi}} \ge 1\text{M}$；
   - **证伪**：若 Qwen 的 $p_{\text{correct}}(\rho)$ 与 $\operatorname{snr}(\rho)/\operatorname{snr}(0)$ 同步衰减（无 W* 相变），则补偿阈值模型不成立，SNR 衰减直接传导为任务失败。

**逐命题判读**：

**预注册证伪标准逐条核对**：

1. "F2 下 $b$ 不增长或 $a$ 显著上升" → **未触发**（F2 下 $b$ 增、$a$ 降）；
2. "$\hat\beta_a$ CI 不含 0" → **触发**（4/4 配置）。按预注册约定，`AttentionMechanism` 的适用域声明须收缩为"弱前提 `ha_nonincr` 成立、强假设 $a$ 常数不成立"——已在 H4 行如实记录；
3. "$r(\rho)$ 显著单调漂移" → **触发**（E3b，2026-10-19）：$r(\rho)$ 漂移斜率均值 $\mathrm{d}r/\mathrm{d}\log\rho=-0.000772$，9 cell bootstrap 95% CI $[-0.001426,-0.000200]$ **不含 0**。方向与预注册示例（$\mathrm{d}r/\mathrm{d}\rho>0$，sink 增长）不同：整体为**显著负漂移**（U 形，0.2579→0.2468→0.2568），且在下降相区间（≥32k）转为正。按实质判据（$r$ 非常数、系统性漂移）二通道叙事不足——须显式三分 $a$ / 填充 / sink，A2 的 `filler := b - r` 口径分离正是为此设计。另：填充口径 SNR 较总量口径高估 35.8%–36.7%（因子 $t/b\approx1.36$，与单点冒烟 33% 一致），与 `snr_le_proxy` 方向一致；
4. H6 下界过保守检验 → 未测（同 H6）。

**对理论的三条结论**（须进正文与附录 B.9）：

- 几何衰减界 $c^\rho$ 的经验前提在 L2 档**不成立**；应替换/补充为幂律分支（A4）。几何界可作为"最强情形的上界参考"保留，但正文必须声明其实测支持弱于幂律；
- $a$ 的 ρ-依赖性（$\hat\beta_a<0$）意味着**实测 SNR 衰减同时来自分子收缩与分母膨胀**，不只是稀释——正文的机制归因须二分；
- 7B YaRN 的下降相提示 YaRN 外推改变了长程注意力分配结构（候选机制：sink 迁移），该现象是**新观测**，不属于原理论预言也不与之矛盾，须作为适用域边界写入。

### T3 设计骨架（两相模型）

```lean
/-- 两相稀释动力学：把「饱和区前提失效」从事后解释提升为定理内的显式结构。 -/
structure PhaseModel (ρ_star : ℝ) where
  hpos : 0 < ρ_star
  c : ℝ
  hc_pos : 0 < c
```

**动机**：当前 $\gamma$（及幂律 $\beta$）只能事后拟合，理论停留在"给定 $\gamma$ 的衰减"。若 $\gamma$ 可由前向传播中**无需标签、无需拟合**即可观测的结构量预测，理论即从描述升级为预测——这是 T8 的唯一目标。

**候选结构量**（均在 `_row_attention_weights` 的 fp32 行重算路径上廉价可得，不改变前向）：

1. **查询行注意力熵** $H(\rho) := -\sum_j p_j \log p_j$（逐层逐头，聚合为层均值）——稀释的"信息熵"直接度量；公理 II 的命名即"注意力熵增"，若 $H$ 与 $\gamma$ 无关则命名仅具隐喻价值；
2. **logit 谱集中度** $\mathrm{top@}k$：softmax 行中质量最大的 $k$ 个位置的总质量（$k\in\{1\%\,S,\ 10\}$）——attention sink 强度的直接度量，E3b 已证 sink 是动态通道；
3. **key 有效秩** $\mathrm{erank}(K) := \exp(-\sum_i \tilde\sigma_i \log \tilde\sigma_i)$，$\tilde\sigma$ 为 $K^\top K$（$d_h\times d_h$）归一化特征值——key 空间的实际维度塌缩度。$S\times d_h$ 的 SVD 在 128k 下不可行，但 $K^\top K$ 恒为 $128\times128$，成本可忽略。

**假设（H_T8）**：存在至少一个结构量 $S$，使跨 cell（filler × position × ρ 档）实测衰减率 $\hat\gamma$（几何拟合）或 $\hat\beta$（幂律拟合，主口径——E3 已判幂律占优）与 $S$ 满足 $|\mathrm{Spearman}\ \rho_S| \ge 0.5$ 且 bootstrap 95% CI 不含 0。

**预注册证伪标准**（先于实验写下）：

- 三个候选结构量与 $\hat\beta$ / $\hat\gamma$ 的 Spearman 相关**均** $|\rho_S| < 0.5$ 或 CI 含 0 ⟹ **T8 关闭**，$\gamma$ 保持自由参数，正文明确"衰减率不可由单层结构量预测"这一负结果；
- 若仅个别层（如首末层）的结构量相关而层均值不相关，须按层分组报告，不得聚合掩盖——与 §3.3 逐层分解口径一致；
- 若相关成立，进入 F 侧：把 $\gamma := g(S)$ 作为 `AttentionMechanism` 的**参数化接口**（定义而非新公理），形式化只承诺"给定 $g$ 的衰减"，$g$ 的函数形式由经验标定——与 T6 的叙事口径一致。

**矩阵与预算**：复用 E3b 矩阵（7B YaRN 4.0，ρ∈{2k,8k,16k,32k,64k,131072}×F1–F3×位置 0.1/0.5/0.9），reps=3（E3b 实测单格 ~26 s，54 cell × 3 ≈ 72 min，免费卡时余额充足）。分析单元为 cell 级 $\hat\beta$（54 个 cell 各拟合幂律指数）对 cell 级结构量均值。

### 8.2.2 E4 设计：W* 补偿阈值模型（2026-10-20）

**动机**：E8 关闭揭示跨模型族结构量不稳定；E4 冒烟进一步发现 Kimi-for-coding 在 1M 上下文内 needle 正确率 ≈ 100%，与 Qwen 在 131k 内已观测到 SNR 衰减形成反差。原 H6 设计假设"SNR 衰减直接传导为任务失败"，但冒烟数据不支持——**SNR 衰减与任务正确率衰减之间存在补偿阈值 W***。

**理论映射（修订）**：

公理 II 的 `violation_prob(ρ) = 1 - snr(ρ)/snr(0)` 是**相对信噪比损失**，不是任务失败概率。两者之间的传导需经补偿机制：

$$p_{\text{correct}}(\rho) = \begin{cases} \approx 1 & \rho < W^* \quad \text{（补偿抵消 SNR 衰减）} \\ \text{陡降} & \rho > W^* \quad \text{（补偿失效）} \end{cases}$$

$W^*$ 是经验参数，与模型的"理智"（注意力 sink 强度、KV cache 策略、长上下文训练对齐程度）正相关。形式系统暂不引入 $W^*$（保持 `violation_prob` 的纯 SNR 定义），但正文与附录 B.9 须声明：**违约下界只在 $\rho > W^*$ 时传导为可观测的任务失败**。

**实验设计（双线并行）**：

| 线 | 平台 | 模型 | 目标 | 关键参数 |
|---|---|---|---|---|
| **主线** | scnet DCU（云端） | Qwen2.5-1.5B/7B × 原生/YaRN 4.0 | 测 $p_{\text{correct}}(\rho)$，与 E3 的 $\operatorname{snr}(\rho)$ 对齐，找 $W^*_{\text{Qwen}}$ | ρ 档复用 E3（0–131k），pos=0.1/0.5/0.9，reps=10 |
| **辅线** | 本地 Kimi API | kimi-for-coding | 用难任务逼近 $W^*_{\text{Kimi}}$，确认 $W^*_{\text{Kimi}} \ge 1\text{M}$ 或找到相变点 | ρ 档 128k/256k/512k/1M，多 needle 检索 + 语义干扰 filler，reps=10 |

**主线脚本**：`e4_qwen_needle.py`（云端）——复用 E3 的模型加载与 ρ 档，生成 needle-in-haystack 上下文，调 model.generate 取答案，判正确率。输出 `e4_qwen_correctness.json`。

**辅线脚本**：`e4_kimi_hard.py`（本地）——在冒烟 v2/v3 基础上升级任务难度：①多 needle（"列出所有魔法颜色"）；②语义干扰 filler（与 needle 同主题的干扰句）。输出 `e4_kimi_hard.json`。

**判读标准**（见 §4.6）：
1. 推论 1：Qwen 正确率序列存在相变点 $W^*$（变点检测）
2. 推论 3：$\operatorname{snr}(\rho)$ 在 $\rho \ll W^*$ 时已衰减但 $p_{\text{correct}} \approx 1$
3. 推论 2：$W^*_{\text{1.5B}} < W^*_{\text{7B}} < W^*_{\text{Kimi}}$
4. 证伪：$p_{\text{correct}}(\rho)$ 与 $\operatorname{snr}(\rho)/\operatorname{snr}(0)$ 同步衰减（无 W* 相变）

**冒烟阶段已知**：Kimi 在 1M 内单 needle 正确率 ≈ 100%（$W^*_{\text{Kimi}} \ge 1\text{M}$）；Qwen 正确率待测。
